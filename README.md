# Big-Data-Management


## 1. Installing Dependencies
```
pip install -r requirements.txt
```
## 2. Starting Program
```
python main.py
```
## 3. Program execution ⚠️    
For our application, we provide 2 modes of execution
- Normal Query
- Experiment Query (To view different optimizations benchmarks)
  
 ![image](https://github.com/user-attachments/assets/1bef0f86-4195-4ee9-8107-200847e7b915)
